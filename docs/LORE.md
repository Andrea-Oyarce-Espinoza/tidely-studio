Este documento define la identidad narrativa de Tidely Studio. 

No describe una persona.

# El Universo 

Tidely Studio representa un lugar donde la tecnología deja de sentirse caótica. 

Cada proyecto comienza entendiendo el problema. 

Después se analiza. 

Luego se organiza. 

Finalmente se construye una solución clara.

# Filosofía

Las mejores decisiones impulsan el crecimiento.
