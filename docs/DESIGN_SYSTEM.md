# Objetivo

Este docuemtno define las reglas visuales de Tidely Studio. 

Su propósito es garantizar una experiencia consistente en el sitio web, productos digitales, documentación y futuras aplicaciones. 

El diseño debe comunicar claridad antes que complejidad. 

---

# Principios

Todo elementos visual debe transmitir: 

• orden

• claridad

• confianza

• tranquilidad

• precisión

• cercanía

---

# Filosofía

El diseño no debe distraer. 

Debe ayudar a comprender. 

Cada elemento tiene un propósito.

Nada existe únicamente como decoración. 

---

# Personalidad Visual 

Queremos transmitir: 

✓ profesionalismo

✓ simplicidad

✓ organización

✓ tecnología

✓ elegancia

✓ calma

Nunca: 

✗ agresividad

✗ saturación

✗ exceso de efectos

✗ apariencia corporativa rígida
