# AUDIT_SYSTEM.md

> Sistema de Auditorías Tidely 
> Versión 1.0

---

# Objetivo

Definir ua metodología única para analizar sitios web de forma consistente. 

---

# Principios

Las herramientas detectan datos. 

Tidely entrega contexto.

---

# Flujo

1. Descubrimiento del negocio

2. Recolección de evidencia

3. Análisis

4. Priorización

5. Elaboración del informe

6. Presentación

7. Seguimiento

---

# Áreas evaluadas

- SEO
- Performance
- Acceisbilidad
- UX
- Responsive
- Seguridad
- Contenido
- Arquitectura

---

# Cada hallazgo incluye

- Descripción
- Evidencia
- Impacto
- Prioridad
- Recomendación
- Beneficio esperado 

---

# Clasificación

🔴 Crítico

Nunca copiar resultados de herramientas.
