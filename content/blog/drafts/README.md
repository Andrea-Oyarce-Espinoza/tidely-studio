# Borradores para revisión de Andrea

La automatización del lunes guarda aquí las propuestas en Markdown. Esta carpeta no se importa ni genera páginas públicas. El calendario y los criterios de voz están en `docs/BLOG_EDITORIAL.md`.

Formato sugerido: `YYYY-MM-DD-slug.md`, con título, descripción, fecha propuesta, cuerpo, pregunta y llamada a conversar. El nombre del archivo y la fecha propuesta no programan la publicación.
